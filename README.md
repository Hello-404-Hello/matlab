# MATLAB 作业与课程项目

## 注意事项！！！！！

在下载代码后一定要用AI使用下面的降重Prompt把代码再过一遍！！！！！

**降重Prompt**：请把以下我给你的代码改一改变量名（不要使用驼峰命名法，变量名尽量简单，可以是中文拼音或中文拼音缩写或a、b、c、aa、aaa等简单变量名），变量赋值顺序做一些调整，保持运算符前后没有空格，少加一点点注释，切忌使用防御性代码或防御性注释说明，在代码中刻意保留一些新手痕迹。输出结果的格式可以微调，输出图片的样式也可微调。

## 第一轮作业

[打开 MATLAB 作业解法库：查看每题下载次数并随机打包下载](https://hello-404-hello.github.io/matlab/)

网站会从仓库读取第 1–22 题的现有解法版本。每次下载时，系统为每题随机抽取一个版本，生成包含 `Q1.m`–`Q22.m` 和所需附件的压缩包，并更新对应版本的下载次数。

已补齐挑战题 Q19–Q22，每题 8 个版本。第一轮共 152 份独立脚本。新版题面见 [基础+高阶+挑战 PDF](第一轮作业题/MATLAB第一轮作业赛题基础+高阶+挑战.pdf)，实测结果见 [挑战题运行结果](第一轮作业题/挑战题运行结果.md)。

作业脚本、运行结果和题目资料见 [`第一轮作业题`](第一轮作业题/)。网站源码和配置说明见 [`web`](web/README.md)。

## 第二轮作业

[查看第二轮题目与下载统计](https://hello-404-hello.github.io/matlab/#round2)。网站顶部的「下载第二轮」按钮会对 18 道题各抽一个版本，并附上题目需要的图片和表格。普通题文件为 `Q题号.m`，Q5 抽奖和 Q17 翻卡以 `Q5.mlapp`、`Q17.mlapp` 提供，可在 MATLAB App Designer 中打开。

Q11–Q18 每题至少 8 个版本。两道 GUI 各有 20 个版本，采用 MATLAB 默认配色，并使用不同的布局和控件。题面、解法和附件见 [第二轮作业题](第二轮作业题/)，各版本的运行数据、图形和界面对照见 [第二轮运行结果](第二轮作业题/运行结果汇总.md)。
